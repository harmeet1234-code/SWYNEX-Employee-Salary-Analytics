## Project Overview
This repository serves as the main submission page for my Data Analytics Internship projects at SWYNEX Technologies. The projects cover data cleaning, exploratory data analysis, and employee salary analytics using Microsoft Excel and Power BI.

## Problem Statement
To improve employee data quality, explore workforce and salary patterns, and present meaningful business insights through data analysis and visualization.

## Dataset Information
- Total Records: 500 employee records
- Departments: Finance, HR, IT, Marketing, and Sales
- Fields include age, city, department, and salary.
- Tools: Microsoft Excel and Power BI

## Project 1: Data Cleaning and Preparation
Cleaned and prepared the employee dataset using Excel, checked missing values and duplicate records, applied median imputation, and reviewed city and department consistency.

[View Project 1 — Data Cleaning](https://github.com/harmeet1234-code/Data-cleaning-project)

## Project 2: Exploratory Data Analysis (EDA)
Explored employee distribution across cities and departments and reviewed salary statistics to identify patterns in the dataset.

[View Project 2 — EDA](https://github.com/harmeet1234-code/Sywnex-Task-2-EDA-)

## Project 3: Employee Salary Analytics Dashboard
Developed an interactive Power BI dashboard featuring average salary, median salary, employee count, department-wise salary comparisons, employee distribution, and interactive filters.

[View Project 3 — Power BI Dashboard](https://github.com/harmeet1234-code/SWYNEX-Employee-Salary-Analytics-Dashboard)

## Key Business Insights
- HR had the highest average salary at 94.51K.
- Sales had the lowest average salary at 89.72K.
- HR had the highest employee count, with 115 records.
- Marketing had the lowest employee count, with 89 records.
- Overall average salary was 92.21K and median salary was 94.06K.

## Conclusion
These projects provided practical experience in data cleaning, exploratory analysis, and dashboard development. Together, they demonstrate how Excel and Power BI can help organize employee data, analyze salary patterns, and communicate business insights.
